## Boundaries and ownership

- `metrics`: reusable fixed-phase counters and duration histograms; observations include unsuccessful attempts, nested phases overlap, and concurrent snapshots are approximate.
- `query`: owns process protocol, selected input staging, immutable request scope, reset/discard, process reaping and bounded worker ownership. The database owns the runtime lifetime.
- `engine`/`policy`: own logical snapshots, ordered commits, generations, protected inputs and atomically published replacement state.
- `wal`: owns immutable encoded frames and durable publication. Byte reuse does not authorize bypassing admission or replay validation.
- Derived-state persistence must include local and remote reachability, format negotiation and fail-closed recovery before it is described as complete.
